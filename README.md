WTWR is a React-based web application that fetches real-time weather data and recommends suitable clothing based on the current temperature.

Features:

    -Live Weather Data: Integrates with the OpenWeather API to fetch and display the current temperature and location.

    -Dynamic Recommendations: Automatically filters a collection of clothing items to recommend the best options (hot, warm, or cold weather) for the current climate.

    -Interactive Modals: Includes a detailed image preview modal for clothing items and a structured form modal for adding new garments.

    -Responsive UI: Built with adaptive design principles to ensure a seamless experience across desktop and mobile devices.

Technologies Used:

    -React.js
    -Vite
    -CSS
    -OpenWeather API
    -GitHub
